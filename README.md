# Hair Botox Birmingham - Project Overview

The project is a high-end, conversion-focused landing page for **Hair Botox Birmingham (Floractive Training)**. It moves the business away from manual DM bookings towards an automated, professional web presence.

## 📁 File Structure
- `index.html`: Main landing page structure.
- `styles.css`: Luxury design system (Rose Gold & Black).
- `script.js`: Interactivity for booking and AI chatbot.
- `assets/`:
    - `logo.png`: Custom logo concept.
    - `hero.png`: High-gloss hair visual.
    - `academy.png`: Training environment visual.
    - `before_after.png`: Treatment result comparison.

## 🚀 Key Features
- **Luxury Hero Section**: Cinematic hair visuals.
- **Academy Portal**: Structured course information for professionals.
- **Booking UI**: Interactive calendar for courses and models.
- **AI Chatbot**: Instant answers to student FAQs.
- **Premium Design**: Rose Gold, Black, and Glassmorphism.

## 🛠️ How to View
Open `index.html` in any modern web browser.
